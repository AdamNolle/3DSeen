# 3DSeen website

Static, dependency-free project site. Serve `website/` with any HTTP static
server or open `website/index.html` directly for local review.

The site follows the approved white wireframe cube on blueprint blue, the
warm-paper Studio palette, and the project's production contract. The hero
wireframe and capture-mode images are illustrations, clearly labeled as such;
they are not app recordings or evidence of physical LiDAR performance.

Feature and readiness copy is grounded in `docs/PRODUCTION-CONTRACT.md` and
`docs/VERIFICATION-STATUS.md`. The current site does not advertise TestFlight,
App Store availability, notarization of the latest revision, or a download.

No site deployment route or verified domain existed in this repository when
this directory was added. Add GitHub homepage metadata only after publication
and URL verification. Real footage requires access to an approved recording of
the current app on a supported Apple device; none is bundled in this repo.
