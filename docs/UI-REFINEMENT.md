# Studio UI refinement

Updated October 1, 2026.

The primary task is to capture, reconstruct, inspect, and export real scans with clear progress and recovery. The interface remains a native SwiftUI workspace in the existing warm-paper and charcoal palette with one cobalt action accent.

The direction uses the focused working surfaces in the design-ui skill's Raycast study, with Remy's continuity between a collection and its selected item. System typography, SF Symbols, real retained thumbnails, and semantic empty states keep the workspace readable. The Library's page-level New Scan action owns the first-run action: the empty-state card explains what belongs there without repeating the button already available in the phone dock or iPad search row. Following the user's final logo selection, a white wireframe cube on blueprint blue replaces the earlier aperture exploration. Both app targets use the shared Apple Icon Composer document, with matching in-app assets and explicit default/dark colors.

On Mac, persistent workspace navigation anchors Library, Compute, Viewer, and Export. Source-list density and translucent sidebar material keep navigation quiet. The selected model carries the visual emphasis. The library uses adaptive columns, clear search results, and a useful first-run action. Compute adapts its supporting event log to smaller windows. Empty states explain the next action without synthetic models or sample scans.

Phone and iPad retain their familiar capture wizard. Library filtering and search must show every matching scan, including the featured scan, and adaptive grids must remain usable in split view. Primary touch controls use generous hit areas. Press feedback respects Reduce Motion; glass respects Reduce Transparency. No decorative motion is required to understand state.

Display type establishes screen and model identity; body type explains the task; monospaced labels are reserved for compact facts. Existing theme tokens supply all surfaces, borders, selection, status, and primary actions. Verification covers rendered empty and selected states, narrow windows, both appearances, enlarged text, and the working navigation and export paths.
